01

Choose what you own 選擇你負責的資產

Add repositories, complete website URLs, or exact approved internal systems. Advanced cloud, container, IaC, and Kubernetes sources stay optional. 加入程式碼專案、完整網站 URL 或精確獲准的內部系統；雲端、容器、IaC 與 Kubernetes 來源維持選用。

02

Run only applicable tools 只執行適用工具

Each scanner receives only the asset and scope it can check. One unavailable tool does not erase findings from completed siblings. 每個掃描器只會取得它能檢查的資產與範圍；單一工具無法執行時，不會抹去其他已完成結果。

03

Read one prioritized report 閱讀一份優先排序報告

See affected assets, impact, evidence, the smallest next action, verification guidance, and exactly what was not tested. 直接看到受影響資產、可能影響、證據、最小下一步、驗證方式，以及哪些項目尚未測試。

The product layer 產品報告層

The scanners stay upstream. The answer becomes yours. 掃描器維持上游原意，答案整理成你的工作視圖。

The shared report layer handles organization, prioritization, plain-language guidance, and cross-engine context without erasing original evidence. 共用報告層負責整理、排序、白話說明與跨引擎脈絡，同時不抹去原始證據。

  • Every requested asset gets one clear status.每個選定資產都有一個清楚狀態。
  • Highest-priority problems and practical next actions come first.優先呈現最重要問題與實際可行的下一步。
  • Completed sibling results survive an independent tool failure.個別工具失敗時，其他已完成結果仍會保留。
  • Original engine, rule ID, severity, evidence, and remediation stay available.原始引擎、規則 ID、嚴重度、證據與修正建議都能查看。
  • Not-tested work and coverage gaps remain visible.未測試項目與涵蓋缺口會清楚保留。
