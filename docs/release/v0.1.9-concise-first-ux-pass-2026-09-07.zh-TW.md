## 結論

本輪完成的是 `v0.1.9` 之後的 source-only concise-first UI／UX 重構。主要頁面的第一層現在只回答三件事：目前狀態、最重要的下一步、使用者按下去會發生什麼。重複說明、技術來源、歷史紀錄、進階格式與低優先選項改用漸進揭露；真正影響安全或結果解讀的 scope、partial／failed 狀態、資料分享後果與復原動作仍保留在第一層。

產品程式碼已推到 GitHub `main`，並以 clean fast-forward 同步至 Castle 的 `/home/ted-h/projects/ai-security-scanner`。已發布的 `v0.1.9` installer 沒有被覆寫；這個 checkpoint 仍需下一版 release 才會成為可安裝交付物。

## 實際改了什麼

### 全域導覽

- Sidebar 只保留 New scan、My scans、Results、Settings 四個主要目的地。
- 移除每個 nav item 的重複提示、品牌副標、重複語言切換與冗長 privacy detail。
- Runtime 的真實狀態與必要 setup／retry action 仍保留；首頁在 runtime 正常時不再重複顯示第二份 ready banner。

### New scan 與 My scans

- 首頁第一層只顯示四個最常用入口；其餘五個 scan 類型放進 `More ways to scan`。
- 移除重複 benefits、journey、anchor 與說明型卡片。
- 建立掃描時先只要求 project name 與 exact target；organization 與 AI-generated question 放進 `Optional project details`。
- AI-generated 預設改為 `unknown`，避免系統替使用者猜答案。

### Coverage／設定掃描

- 從一頁內重複解釋三次流程，改成三個直接區段：Add inputs、Review items、Review and start。
- 已連接來源清單預設收合；demo 中八張來源卡現在只佔一行 `Sources (8)`。
- unknown source、connected-but-empty、incomplete 與未設定數量仍在第一層顯示。
- Network、cloud、local 三種 guided path 的 exact boundary 留在 Advanced 外：目標、protocol／port／rate／timeout、唯讀模式、保存副本與不修改原始資料的承諾都可直接看見。
- 只有需要處理或目前選取的 asset 顯示 next step；完成項目不再重複泛用建議。

### Progress 與 Results

- Run overview、run identity、blocker／recovery 排在 activity 與歷史之前。
- 普通 completed engine 改成 compact row，只保留名稱、Completed、finding count 與可展開 provenance；不再重複 100% progress bar 與「review results」建議。
- partial、failed、not-executed、cancelled 與 localhost check 不會被壓縮，仍直接顯示錯誤、範圍、下一步與 checkpoint。
- Results 先顯示 priority findings，再顯示 master report；requested target、tested work、第一個 gap 與最高優先 next action 形成固定 truth strip。
- Scope／limitations、correlation、history 與技術紀錄改為收合，但 incomplete／non-final 與 non-certifying framework wording 仍可見。

### Export 與 Settings

- Export 第一層只保留 HTML 與 master JSON；bundle、framework、OCSF、OSCAL 放進 Advanced。
- Raw source toggle 只在 case bundle 出現；可讀識別資訊與 raw source 分享後果分別顯示 warning／danger。
- Export history、exact contents 與技術細節預設收合；Save 仍必須等 preview identity 精確匹配後才可使用。
- Settings 只保留 Language、Safety、Local tools；移除重複的 continue-working actions。

## UI／UX 實際走查

使用同一份最新 source 的 browser dev surface 做視覺走查，逐頁檢查：

1. Start：四個主入口清楚，其餘選項收合；沒有第二份 runtime ready 訊息。
2. New scan：實際開啟 website form；首屏只有 project name、website/API URL、必要安全提示，optional fields 收合。沒有送出表單。
3. My scans：目前案件與 phase-appropriate action 可辨識，沒有新增重複 hero 說明。
4. Coverage：來源 ledger 收合；unknown／empty truth 仍可見；guided exact boundaries 不依賴 Advanced。
5. Progress：completed rows 已壓縮；有問題的 rows 仍保留 recovery、progress 與 technical details。
6. Results：priority findings 與四項 truth strip 在第一屏；master report 細節可展開。
7. Export：兩個常用格式、privacy consequence 與主要 Save action 優先；advanced formats／history 收合。
8. Settings：只剩三個必要區塊，第一層沒有重複導引。

這是 source-level browser visual smoke，不是 Windows native interaction evidence。本輪桌面 Codex 沒有可控制的 native app surface，因此沒有把 browser demo 冒充 installer E2E。先前完成的 installed Windows reopen／report／native Save dialog／export verification 證據仍記錄在 `docs/release/v0.1.9-windows-native-ui-e2e-2026-09-07.zh-TW.md`。
