## Additional installed-candidate exercise

The exact Debian candidate was exercised using its extracted installed layout and isolated application data. This supplements the fresh-runner package installation above; it does not claim a second system-wide installation or a beginner human study. The real desktop started its private managed runtime and ran Gitleaks and Semgrep against a controlled three-file local snapshot. Both checks completed with exit code 0: Semgrep reported four findings and Gitleaks reported none. Six raw artifacts, the original rule identifiers, severity and evidence were retained.

The English and Traditional Chinese Results screens rendered, both redacted HTML reports were saved through the desktop, and reopening preserved all four finding identifiers and fingerprints. The synthetic token was absent from both exports. Browser checks at 390, 768 and 1440 pixels found no script errors. At 768 pixels the report has horizontal scrolling; the 390- and 1440-pixel layouts fit their viewport. This tablet-width export limitation remains a follow-up.
