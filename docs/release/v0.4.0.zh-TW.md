# v0.4.0

[English](v0.4.0.md) · [發布索引](README.zh-TW.md)

[v0.4.0](https://github.com/teddashh/ai-security-scanner/releases/tag/v0.4.0) 已於 2026-10-04 依負責人決定發布為 Linux、macOS 與 Windows 的 **stable／latest 正式版**，整合 25 個上游專案。

## 更新內容

- 可選的 ZAP 被動網站檢查只爬取一個核准來源，保留上游警示、實例、
  嚴重度、證據與修正建議。
- 可選的 Agentic Radar 以一個明確選定的 LangGraph、CrewAI、n8n、
  OpenAI Agents 或 AutoGen 框架，離線盤點保存儲存庫中的工作流程。
  解析診斷會保留；流程盤點不會變成弱點。
- 可選的 Garak 模型檢查針對一個核准 OpenAI 相容 HTTPS 聊天 API 與模型，
  使用 54 個未修改的原生 DAN／ANSI 提示及四組原生偵測器。
  每次需要新的確認與一次性本機金鑰；TLS 驗證、禁止重新導向、
  請求與逾時上限及服務商費用均明確列出。
- Kubescape 缺漏或未評估結果維持未完成，其他已完成發現仍保留；
  大型報告在證據限制內以串流方式處理。
- Greenbone 工作與復原狀態分別綁定精確授權。
- HTML 報告改善長識別碼與平板版面；Microsoft 365 平台辨識已修正。
- Gitleaks `8.30.1-2` 修正可重現的 fixture 建置。
  每個引擎及閘道器都有[建置更新筆記](../engines/image-build-index.md)，
  記錄固定輸入、資料、patch 例外與必須同步的修改。

閘道器映像保留已驗證的 `0.3.0-1` 發布內容；桌面版本更新不會重建相同位元組。

## 額外安裝版操作

以精確 Debian 套件解開的安裝目錄及隔離 app 資料操作，補充全新 runner 的套件安裝；不宣稱另一次系統安裝。真實桌面透過 managed runtime 掃描三個受控檔案，Gitleaks 與 Semgrep 均完成且 exit code 為 0；Semgrep 四項發現，Gitleaks 零項。六個原始 artifact，以及原生識別碼、嚴重度與證據均保留。

中英文 Results 已呈現，兩份遮蔽 HTML 報告由桌面存檔；重開案件後，四項發現的識別碼與 fingerprint 一致，兩份匯出均沒有合成 token。390、768、1440 像素的報告無文件溢出或 script error；先前平板寬度問題已在 v0.4.0 安裝位元組修正。

另以已發布映像驗證 ZAP 來源邊界、原生被動警示與取消；Agentic Radar 五種框架、空專案與環境隔離；Garak 正向、乾淨、重新導向、無效 TLS、期限與取消。以上原生觀察為 amd64，不宣稱 arm64 原生實測。案件稽核使用保存的 fixture，驗證 25 個工具的報告路徑、完整模型歸屬、其他已完成結果保留、保存重開與中英文匯出；盤點不會列為安全發現。
