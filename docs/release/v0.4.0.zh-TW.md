# v0.4.0

[English](v0.4.0.md) · [發布索引](README.zh-TW.md)

負責人已選定**包含新功能的 v0.4.0 正式版**。本頁正在準備；凍結安裝包、
發布與實際交付觀察完成後會在此記錄。目前已發布的版本仍是 v0.3.1。

## 更新內容

- 可選的 ZAP 被動網站檢查只爬取一個核准來源，保留上游警示、實例、
  嚴重度、證據與修正建議。
- 可選的 Agentic Radar 以一個明確選定的 LangGraph、CrewAI、n8n、
  OpenAI Agents 或 AutoGen 框架，離線盤點保存儲存庫中的工作流程。
  解析診斷會保留；流程盤點不會變成弱點。
- 可選的 Garak 模型檢查針對一個核准 OpenAI 相容 HTTPS 聊天 API 與模型，
  使用 54 個未修改的原生 DAN／ANSI 提示及四組原生偵測器。
  每次需要新的確認與一次性本機金鑰；TLS 驗證、禁止重新導向、
  請求與逾時上限及服務商費用均明確列出。
- Kubescape 缺漏或未評估結果維持未完成，其他已完成發現仍保留；
  大型報告在證據限制內以串流方式處理。
- Greenbone 工作與復原狀態分別綁定精確授權。
- HTML 報告改善長識別碼與平板版面；Microsoft 365 平台辨識已修正。
- Gitleaks `8.30.1-2` 修正可重現的 fixture 建置。
  每個引擎及閘道器都有[建置更新筆記](../engines/image-build-index.md)，
  記錄固定輸入、資料、patch 例外與必須同步的修改。

閘道器映像保留已驗證的 `0.3.0-1` 發布內容；桌面版本更新不會重建相同位元組。

## 交付觀察

安裝檔與公開位元組驗證尚待完成。Windows 未簽章，macOS 的簽章與公證
仍未設定；本版不宣稱已完成擁有者重新登入的 Microsoft 365 最新實測，
也不宣稱已完成新手真人路徑研究。

精確來源、候選包與發布 artifact 選擇值、檢查碼、更新目標、平台驗證，
以及受控安裝版操作結果，會在驗證後補上。
