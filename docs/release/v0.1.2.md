# v0.1.2 historical change summary

This record summarizes the public-testing product changes made on the `v0.1.2` line. It is not current guidance; see the [product specification](../product-spec.md).

## Useful changes retained

- English and Traditional Chinese covered the full interface and both README entry points.
- The first layer used target types—website, IP, source, cloud, container, and Kubernetes—instead of scanner names.
- Engine state, identifiers, protocols, hashes, and limits moved to optional technical detail.
- Cloud setup led with a non-secret handoff file and the provider's official sign-in page.
- Repository, IaC, OCI image-layout, Kubernetes manifest, and node-configuration inputs used typed immutable snapshots.
- Provider work stayed bound to one exact AWS account, Azure subscription, GCP project, or Microsoft 365 tenant.

The setup-first funnel used by this old line is superseded. Current behavior starts from the user's scan task and keeps runtime preparation behind that task.
