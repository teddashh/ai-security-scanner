# v0.1.6 historical change summary

This record summarizes managed connection and source-scan changes made on the `v0.1.6` line. It is not current guidance; see the [product specification](../product-spec.md).

## Useful changes retained

- The managed egress gateway moved beside scanners inside the private runtime, with separate scanner and uplink networks.
- Gateway state came from the running component instead of a stale desktop status.
- Gateway failure retained a concrete task outcome and cleanup result.
- The Gitleaks path used pinned upstream source, scanner-owned rules, a read-only worktree, no network, and full secret redaction.
- A secret match remained a finding instead of being mistaken for process failure.
- The AI project starting point reused existing code, secret, dependency, and deployment checks.

VibeScan was studied for its guided journey and common result-envelope ideas but was not wrapped or executed. The product continued to use its selected upstream scanners and shared report layer.
