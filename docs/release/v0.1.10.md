# ai-security-scanner v0.1.10

Release channel: public prerelease

## Highlights

- Home leads with one IT environment, one website, and one project folder.
- A mixed IT-environment run binds repositories, websites, and exact internal systems to their applicable upstream checks.
- Active work stays in Progress; terminal Results and Export use one durable report model.
- Every selected asset receives a direct problems-found, no-problems-in-completed-checks, incomplete-or-failed, or not-tested state.
- Finding priorities lead with impact, next action, and verification guidance; upstream evidence remains available in technical details.
- No-checks-completed runs remain visible as terminal outcomes and are excluded from verification baselines.
- English and Traditional Chinese documentation now covers installation, first scan, scope, results, export, and release operations.

## Desktop packages

The release workflow builds and qualifies Linux x86-64, macOS Universal, and Windows x86-64 installers. Published files include exact checksums, runtime manifests, engine notices, SBOMs, and platform qualification records.
