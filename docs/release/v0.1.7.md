# v0.1.7 historical change summary

This record summarizes reliability changes made on the `v0.1.7` line. It is not current guidance; see the [product specification](../product-spec.md).

## Useful changes retained

- Public and internal network inputs accepted an IP address or domain, froze resolved addresses into the run, and stayed within the selected target and bounded port preset.
- Event listeners attached before startup reconciliation so fast progress and completion events were not lost.
- A stopped scan retained saved evidence and distinguished retry from a new run.
- Project snapshots kept files when trusted ignore evaluation was unavailable rather than silently omitting them.
- Trivy used the selected input type; Grype provided complementary OCI package and archive coverage.
- Runtime recovery required exact ownership before modifying old state. Uncertain state was preserved while a new isolated generation could be created.

These changes support durable, understandable scan results. Historical platform testing and distribution decisions are intentionally not carried forward as product requirements.
