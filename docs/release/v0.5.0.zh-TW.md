# v0.5.0 整合安裝包

[English](v0.5.0.md) · [發布紀錄](README.zh-TW.md)

狀態：Windows、macOS 與 Linux 安裝包已完成建置與驗證，交付為綁定精確來源的驗收包。目前已公開的正式版仍是 [v0.4.1](v0.4.1.zh-TW.md)；v0.5.0 尚未公開發布。

本版收納 v0.4.1 來源 `94ef7be18e83630553d9a72746b0533695df1ee2` 之後，到 `c5a0a6693a1ad9997ee16b9a3d690d38a44b7406` 為止的全部 32 筆提交。其中一筆記錄前版交付，另外 31 筆包含產品、報告與文件更新；大小更新均列於[完整提交清單](v0.5.0-changes.json)。

## 桌面與報告更新

- **同一個問題合併成一張卡。** 相同弱點套件、相同外洩秘密，以及同一行且同一 CWE 的程式碼發現合併呈現。保留原始發現、上游識別碼、證據、嚴重度與修正建議，顯示原始發現數及報告選定的代表發現。
- **修復後重掃以問題卡比對。** 區分已修復、部分修復、仍存在及新增問題；行號移動時保留代表發現，部分修復顯示尚存的原始發現數。桌面與 HTML 比對報告使用 Results 的一致排序。
- **重新選取最新本機資料夾。** 重掃前可再次選取資料夾，在核准範圍內建立新的唯讀快照，舊掃描證據仍可比對；我的掃描改以最近完成掃描計算問題數。
- **下一步更貼近問題。** 雲端設定、身分與雲端資源採用合適的標籤和處理建議。合併建議說明是否共用一項修正、在哪裡修及如何確認；區分上游嚴重度、基準分類與產品處理順序。
- **進度與工具資訊更清楚。** 區分部分完成與失敗；顯示工具版本、更新日期及來源建置的 commit 資訊；盤點工具不再要求不適用的弱點資料更新。

## 指南與範例更新

- 補齊每個工具是什麼、如何運作及為何納入產品的說明，修正引擎目錄、輸出格式和示範版本。
- 發布並更新中英文[真實修復與重掃範例](../check-fixes-demo.html)，含修復前後 HTML 報告、問題卡與最新比對截圖。
- 新增掃描、派送、信任邊界、重掃、報告與模型檢查限制的動畫圖解，並改用易懂文案。

沿用既有 25 個上游工具整合與固定映像 digest；v0.4.1 已交付的 HTML 原始報告附件及存取清理輔助程式也包含在整合版中。

Linux runtime 建置另將 Alpine `zlib-dev`、`zlib-static` 固定為可取得的 `1.3.2-r1`，`libseccomp-static` 固定為 `2.6.1-r0`，修正舊套件已從索引移除而無法建置的問題；runtime 程式會由打包流程重新建置並驗證。

另納入兩項依賴安全更新：執行時使用的 rustls 更新至 `0.23.45`（[TLS 公告](https://github.com/advisories/GHSA-2mjx-qc3c-rqvc)），建置時使用的 source-map-js 更新至 `1.2.2`（[source-map 公告](https://github.com/advisories/GHSA-68fv-2mgg-jv7q)）。這些修正與已完成的產品更新一起納入整合版。
