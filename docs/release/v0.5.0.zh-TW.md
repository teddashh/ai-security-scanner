本版收納 v0.4.1 來源 `94ef7be18e83630553d9a72746b0533695df1ee2` 之後，到 `c5a0a6693a1ad9997ee16b9a3d690d38a44b7406` 為止的全部 32 筆提交。其中一筆記錄前版交付，另外 31 筆包含產品、報告與文件更新；大小更新均列於[完整提交清單](v0.5.0-changes.json)。

## 桌面與報告更新

- **同一個問題合併成一張卡。** 相同弱點套件、相同外洩秘密，以及同一行且同一 CWE 的程式碼發現合併呈現。保留原始發現、上游識別碼、證據、嚴重度與修正建議，顯示原始發現數及報告選定的代表發現。
- **修復後重掃以問題卡比對。** 區分已修復、部分修復、仍存在及新增問題；行號移動時保留代表發現，部分修復顯示尚存的原始發現數。桌面與 HTML 比對報告使用 Results 的一致排序。
- **重新選取最新本機資料夾。** 重掃前可再次選取資料夾，在核准範圍內建立新的唯讀快照，舊掃描證據仍可比對；我的掃描改以最近完成掃描計算問題數。
- **下一步更貼近問題。** 雲端設定、身分與雲端資源採用合適的標籤和處理建議。合併建議說明是否共用一項修正、在哪裡修及如何確認；區分上游嚴重度、基準分類與產品處理順序。
- **進度與工具資訊更清楚。** 區分部分完成與失敗；顯示工具版本、更新日期及來源建置的 commit 資訊；盤點工具不再要求不適用的弱點資料更新。

## 指南與範例更新

## 安裝包驗證

打包流程將各安裝檔、SHA-256、runtime manifest、授權聲明、SBOM 與平台觀察綁定同一個精確來源。實際提供的安裝檔以 finalized metadata 為準；完成後補上 run 與 artifact 紀錄。

本機準備通過 2,193 項 Rust 測試（一項公開範例產生器依設計略過）、902 項前端、569 項元件、203 項發布證據、91 項 CI 契約及八項引擎契約。25 個引擎計畫涵蓋的 213 個追蹤輸入均有雜湊紀錄。型別、格式、正式建置、版本一致性與完整打包自測也通過；本機沒有 `pwsh`，33 項 PowerShell fixture 測試明確略過，這些測試不代表真實雲端掃描。

Windows 安裝檔仍未簽章，macOS 仍未公證。舊版 runtime 或安裝操作觀察僅適用原安裝檔，不會列為 v0.5.0 新驗證；此次打包也不包含新的外部目標掃描授權。
