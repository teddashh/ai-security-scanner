# v0.4.1

[English](v0.4.1.md) · [發布索引](README.zh-TW.md)

[v0.4.1](https://github.com/teddashh/ai-security-scanner/releases/tag/v0.4.1) 已於 2026-10-05 依產品擁有者指定，發布為 Linux、macOS 與 Windows 的 **stable／latest 正式版**。

## 更新內容

- 英文與繁體中文 HTML 報告最後可附上原始掃描報告與支援檔案 ZIP；保留各工具的原始位元組、相對資料夾結構與 SHA-256 清單。附件預設關閉，僅供未遮蔽匯出使用，且只包含選定掃描。列印成 PDF 不會攜帶附件。
- 附件匯出前核對檔案歸屬、大小、路徑與雜湊。原始檔超過 64 MiB 或 10,000 個檔案時，會提示改用案件包，不會默默截斷。
- 結果、公開範例報告與工具指南更清楚說明發現、未完成的檢查及下一步。
- 臨時憑證檔一建立就納入清理保護，後續驗證失敗也會清理；既有檔案保留。
- AWS 與 Microsoft 365 設定輔助程式保存臨時存取紀錄；明確啟動的配套清理程式可等待指定掃描、保存報告並撤除該次設定記錄的權限。這尚非桌面程式的預設收尾行為，詳見[操作說明](../../cloud-setup/README.md)。

整合的 25 個上游專案與固定掃描映像維持不變；閘道器沿用已查驗的 `0.3.0-1` 映像。

## 報告驗證

本機通過 2,120 項 Rust、529 項介面元件、前端測試、42 項模擬雲端回應的 PowerShell 設定測試、203 項發行證據與 91 項 CI 契約測試；發行流程自測、引擎目錄、公開範例與正式建置亦通過。附件測試涵蓋原始位元組還原、選定掃描隔離、未完成的其他工具結果、遮蔽、竄改、缺檔、路徑衝突與符號連結。瀏覽器檢查涵蓋中英文及 390、768、1440 像素寬度，並驗證 ZIP 下載與解壓後的原始報告。

另將精確 Debian 套件解開到隔離目錄，以內附 CLI 重開既有受控 Gitleaks／Semgrep 案件的副本，匯出中英文附附件報告。每份 HTML 均含兩個 ZIP、全部六個原始檔，內容逐位元組一致，匯出完整性也通過。另由實際桌面勾選附件並透過存檔對話框儲存英文報告，內容與已驗證的 CLI 報告完全一致。這是安裝目錄中的匯出檢查，不宣稱新的掃描或另一次系統安裝。真實私人掃描報告留在本機，不會成為公開發布附件。

AWS 與 Microsoft 365 輔助程式以模擬雲端回應驗證；新版完整真實雲端設定、掃描、匯出與撤權流程，以及 Windows PowerShell 5.1 執行仍未觀察。升級不會自動撤除既有雲端權限。
