# v0.1.8 historical change summary

This record summarizes product and recovery changes made on the `v0.1.8` line. It is not current guidance; see the [product specification](../product-spec.md).

## Useful changes retained

- The workspace could open while product-owned setup reconciled in the background.
- Interrupted setup resumed from durable recovery records.
- Verified product-owned disposable runtime state could be rebuilt; uncertain state stayed untouched beside a new isolated generation.
- Case data remained outside disposable runtime state.
- Existing cases and export identity stayed durable across application changes.
- A missing private export key affected only an explicitly requested signed bundle; readable unsigned reports remained available.
- The combined report could include optional NIST, ISO, and AIDEFEND relationships without presenting them as audit results or security conclusions.

## Removed design

The version-specific WSL export/import/quarantine transaction and manual recovery journey described by early drafts were removed. Name similarity, a stale marker, or a missing executable never became deletion authority. Historical fixtures and localhost TCP checks remain diagnostic records only; they are not evidence that a meaningful security scan ran.
