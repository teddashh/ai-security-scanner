# 專業精簡介面歷史紀錄（2026-09-07）

本檔只保存當時的介面改動、實際走查與未執行項目。版本與發布尺度由產品 owner 決定。

## 介面改動

- Start、Cases、Coverage、Progress、Findings、Export 與 Settings 的第一層改為只呈現當下狀態、風險、範圍、限制與主要動作。
- 次要說明、技術細節、framework filters、更多格式與進階選項改為 progressive disclosure。
- Findings 把 priority items 放在 metrics 前，缺少資料時明示 unavailable，不以空值假裝完整。
- Progress 保留目前 stage、bytes 與進度；Export 預設顯示 HTML／JSON；Settings 聚焦 language、storage/privacy 與 local tools。
- App shell 合併重複 notice，但保留同時存在的 recovery、stale data 與 selection errors；provider 狀態依 case 隔離。
