# v0.1.5 historical change summary

This record summarizes startup and progress changes made on the `v0.1.5` line. It is not current guidance; see the [product specification](../product-spec.md).

## Useful changes retained

- Website, IP, network, source, infrastructure-code, cloud, container, and Kubernetes routes shared one timestamped activity model.
- The interface named a failed check's useful next action and kept its coverage gap in the combined report.
- Diagnostics retained stable codes and safe statuses, phases, versions, and counts while excluding sensitive target and evidence content.
- Runtime preparation did not contact a target or begin a scan without the user's Start action.
- Existing cases, evidence, cleanup records, and provenance survived startup and tool preparation.

The global Ready/Repair experience is superseded. Current behavior opens the workspace immediately and prepares only the tools needed by the selected task.
