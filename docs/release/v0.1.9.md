# v0.1.9 產品變更歷史摘要

本頁只記錄該時點的產品內容，不設定目前 roadmap、版本或發布尺度；相關決定由產品 owner 掌握。現在的產品方向以[產品規格](../product-spec.md)為準。

## 產品變更

- Managed runtime 可從 digest-anchored packaged cache 復原產品擁有的材料；不明或無關狀態保持不動，engine failure 只影響相依工作。
- Report 與 Results 更清楚區分 completed、partial、failed、disputed、unattributed 與 not-tested work。
- Finding summary、impact、priority、next step、warning、tested dimension、limitation、control mapping 與 verification explanation 支援英文與繁中呈現。
- 多個 scanner 的相關 observation 可在保留各自 evidence 的情況下分組；無法歸屬 known source 的 cloud identifier 在 redacted export 中不輸出。
- 改善桌面 layout、focus、字級、reduced motion 與 compact navigation。
- Microsoft 365 與 managed-image adapters 保留 partial／disputed outcomes，不把缺少 control 或無法讀取的 output 當作乾淨結果。

## 當時已知限制

- Partial report、zero findings 或 unavailable scanner 不代表未執行範圍沒有問題。
- Microsoft 365 與 managed-image engines 當時是分開提供的 artifacts，未包含在 desktop package 中。
- 該時點的自動測試與 fixture 不等於真正新手完成了一次有意義的安全掃描。
