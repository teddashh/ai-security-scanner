# v0.4.1

[繁體中文](v0.4.1.zh-TW.md) · [Release index](README.md)

[v0.4.1](https://github.com/teddashh/ai-security-scanner/releases/tag/v0.4.1) was published on 2026-10-05 as the owner-selected **stable/latest** release for Linux, macOS and Windows.

## Changes

- English and Traditional Chinese HTML reports can include original scanner reports and supporting files as ZIP attachments at the end. Each scanner run retains its original bytes, relative folders and a SHA-256 manifest. Attachments are optional, available for unredacted exports and limited to the selected scan. Printing to PDF does not carry the attachments.
- Attachment export verifies file identity, size, paths and hashes before writing the report. Reports with more than 64 MiB of raw files or 10,000 files direct the user to a case bundle; files are never silently truncated.
- Results, public sample reports and scanner guides explain findings, incomplete checks and next steps more clearly.
- Temporary credential files enter cleanup protection immediately after creation, including subsequent validation failures. Existing files are preserved.
- AWS and Microsoft 365 setup helpers record temporary access. Explicitly started companion cleanup scripts can wait for a selected scan, save its report and revoke access recorded by that setup. They are not yet the desktop app's default completion behavior. See the [helper instructions](../../cloud-setup/README.md).

The 25 upstream projects and their pinned scanner images remain unchanged. The gateway retains its verified `0.3.0-1` image.

Local verification passed 2,120 Rust tests, 529 component tests, the frontend suite, all 42 PowerShell cloud-setup tests using simulated responses, 203 release-evidence tests, 91 CI-contract tests, release self-tests, catalog checks, public showcase checks and the production build. Attachment tests cover exact-byte round trips, selected-scan isolation, incomplete sibling results, redaction, tampering, missing files, path collisions and symlinks. Browser checks cover English and Traditional Chinese at 390, 768 and 1440 pixels, ZIP downloads and opening an extracted original report.

The exact frozen Debian package was also extracted to an isolated directory. Its packaged CLI reopened a copy of the existing controlled Gitleaks/Semgrep case and exported both languages with attachments. The native desktop also saved the English report through its file dialog after selecting attachments; its bytes matched the verified CLI report. This is an installed-layout export check; it does not claim a new scan or another system-wide installation. Actual private scan reports remain local and are not release assets.

AWS and Microsoft 365 helper verification uses simulated cloud responses. New full live-cloud setup/scan/export/revoke flows and Windows PowerShell 5.1 execution remain unobserved. Existing cloud access is not automatically revoked by upgrading.
