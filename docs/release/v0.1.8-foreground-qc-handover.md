  Windows setups into an isolated generation beginning at generation 1.

  snapshots, uninstall staging, and Windows DACL admission without rewriting

  unaffected saved cases and reports remain accessible.

  case/run/locale coordinates, with stale coordinates failing closed.

  HTML reports while retaining standard redaction.

  raw-evidence, serializer, redaction, or signature claims.

  permanently poisoning retries. Existing collisions are preserved; recovery

## Failures found and fixed

- CI run `33695158579` at `main@1d4054e` exposed a real minimal-feature build
  failure: shared library code referenced `directories` while the dependency
  was optional under the CLI feature. It also exposed three Windows fixture
  failures because the hosted runner created roots owned by Administrators.
  The shared dependency is now always available, and only the test helper sets
  an explicit current-user owner. Production ACL admission was not weakened.
- The gateway publication run `33695158567` correctly refused to overwrite
  immutable tag `0.1.8-1`, which was already bound by run `33243068682` to
  source `59e34af14f4aa829419ae8cafa9fa352e2e450c2` and index digest
  `sha256:9f0575f58a6329740eca6a042f8c9d44a3af25144fc80946956823924c445725`.
  Build, publication, evidence, and promotion were skipped and the existing tag
  was unchanged. The workflow is now manual-only and keeps the immutable guard.
- CI run `33696772321` at `fa13835` then caught a test-design mistake: a
  classifier test imported `yaml` even though that job intentionally does not
  run `npm ci`. The test was made dependency-free at `2cb7a23`; all 23 CI
  contracts passed. The resulting green run `33696908514` scheduled only the
  classifier and aggregate jobs, so it is not presented as full heavy-lane CI.

## Open specification and security gaps

1. **P0 A19 same-version packaged-component repair remains open.** The running
   app has no independent authenticated same-version installer or payload
   cache. Safe task-scoped degradation and recovery guidance are implemented,
   but complete exit/repair/relaunch and installed-Windows qualification are
   not.
2. Signed-bundle scope is implemented as case-wide records plus run-bound
   reports, including an explicit current-projection caveat. Real signed-bundle
   installed and human-path qualification remains open.
3. GitHub Dependabot alert #1 remains open for Cargo `glib 0.18.5`:
   `GHSA-wrw7-89jp-8q8g` / `RUSTSEC-2024-0429`, Moderate 6.9. It is in the
   Linux desktop Tauri/GTK3 graph; Windows and Linux CLI-only graphs exclude it.
   `gtk 0.18.2` requires `glib ^0.18`, so a lockfile-only update to patched
   `0.20.0` is not valid. A short-term fix requires an audited immutable
   fork/vendor backport; the long-term fix is a GTK4/Tauri migration.
4. Administrators-owned, conditional/object-ACE, or foreign-inheritable-write
   legacy product roots deliberately fail closed. Enterprise policy
   compatibility needs real qualification before broadening admission.
5. The Nuclei production image gate, new immutable recipe/tag, digest,
   attestation, and publication were not implemented or run.
6. The Vite main chunk remains about 878 kB minified / 266 kB gzip. Treat it as
   a measured optimization candidate, not an unrelated release gate.
