## 必須分開的兩個 payload

### 1. Clean BEGINNER guest payload

新的可重置、拋棄式 Windows x86-64 guest 只能包含：

- 上述精確 installer；
- 選配且確實來自同一 public release 的 `SHA256SUMS.txt`、`release-assets.json` 或其他唯讀公開驗證資料。

不可把 observer handoff、Node、validator、worksheet、source checkout、qualification harness、private diagnostics 或 agent UI 放進 guest。參與者不得看見 Codex UI。

Installer 必須在 session 外預先下載、核對檔名、byte length 與 SHA-256，再凍結 guest snapshot。不得在真人計時開始後安裝工具、修改 candidate 或臨時加入 fixture。BEGINNER 不使用 WL-13 fixture；`127.0.0.1:9001` 應保持未綁定。若已由 BAT、未知 process 或其他未核准 owner 綁定，停止並回報 `not-observed`，不可停止或重新設定該 owner。

### 2. Observer payload

Observer payload 留在 guest 外，participant 看不到，至少包含：

- 本文件、正式產品規格、Windows 外部資格驗證計畫與凍結的 identity-only candidate handoff；
- `validate-v019-beginner-human-path.mjs`、與它同版的 `artifact-evidence.mjs` 和 `utc-timestamp.mjs`；
- 空的專用 `redacted-output/`；
- 與 import root 分離的空 `private-diagnostic/`；
- 不包含 canonical evidence 的空白 observer worksheet；
- 列出每一份 payload file 的 SHA-256 manifest，以及由維護者在聊天外另行提供的外層 archive SHA-256。

這些 post-release observer tools 不是 v0.1.9 release asset。它們只能驗證交回紀錄的 shape 與固定 identity，不能證明觀察內容為真。每個真人 session 使用全新的空 output directories；不可讓先前 signing 或 lifecycle 檔案混入 BEGINNER local-validator inventory。

## Session 前置條件

只有全部成立才開始：

- participant 沒有 build、contribute 本產品，也沒有使用或預演這份 candidate；
- participant 自述沒有與本任務相關的 security-scanner 或 Linux／WSL 經驗；
- participant 已同意 structured observation，以及任何另外選擇的 private screenshot／recording retention；
- guest 是指定的乾淨、可重置、拋棄式 Windows x86-64 snapshot，沒有個人帳號、客戶資料、production target 或 provider credential；
- recorder 已在不保存 account name、SID、device name 或個人路徑下記錄 Windows edition／version／build、architecture、account privilege／UAC model、virtualization capability、initial WSL state、snapshot ID 與 network profile；
- 已透過審查過的唯讀方式確認 Windows host `127.0.0.1:9001` 未綁定；
- 精確 installer identity 全部相符，且先前獨立 signing observation 沒有發現 `Invalid`、`HashMismatch`、unexpected signed state 或其他 integrity stop；

## Canonical record 與本機驗證

它必須完全符合 `artifact-evidence.mjs` 的 exact schema。不可加入 consent、snapshot、workflow selector、private retention reference、export hash 或其他額外 keys。這些資訊留在 worksheet／session summary。不得配送 populated passing example，也不得從 rehearsal、測試 fixture、摘要或舊 session 複製數值。
