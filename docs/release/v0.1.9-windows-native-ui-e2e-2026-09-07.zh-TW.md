## 產品修正

- Runtime unavailable 文案只描述受影響的進階工具，不再暗示所有本機功能都不可用。
- 完成狀態改為綁定 requested checks，不暗示整個系統安全。
- 單純連線紀錄固定揭露未測範圍，即使保存的 gap count 是 0。
- Mixed-run 不誤套 localhost 限制；missing／stale run fail closed，不代換別輪資料。
- Export 顯示 completed scanner job count，並明示 job 完成不等於廣泛安全涵蓋。
- 修正後的 Windows debug build 已重新查看首頁與 Results 關鍵文案。
