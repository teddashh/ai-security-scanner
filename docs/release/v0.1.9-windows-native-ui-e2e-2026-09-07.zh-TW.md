## 本輪修正的 UI／UX 問題

1. **Runtime scope 說得太大**：舊文案容易讓新手以為所有本機功能都不可用。現在只說進階工具未就緒，並明示 localhost quick check 與已保存結果仍可使用。
2. **完成狀態容易誤讀成整台電腦安全**：`Complete` 改成「要求的檢查已完成」，讓 completion 綁定 requested checks。
3. **零 gap 容易掩蓋未測範圍**：即使 recorded gap count 為 0，exact quick-check 仍顯示漏洞、協定、內容、其他 port／host 未測。
4. **Mixed run 可能誤套 localhost 限制**：exact quick-check disclosure 現在只在整輪確實符合 built-in localhost quick-scan identity 時顯示，不會覆蓋含其他 engine 的 mixed run。
5. **缺少 durable report 時恢復指引不夠準確**：若精確 run 仍存在，文案導向 scanner status 與 export，不再說結果「在下方」。
6. **Stale selected-run 誤導**：若 route 指向不存在的 run，現在 fail closed；不代換另一輪資料，也不承諾不可用的 Progress／Export。
7. **Export 看不出到底完成幾個 scanner jobs**：新增 completed job count，計算為 selected 減 incomplete 與 not-executed，並明示 completed jobs 不代表廣泛安全涵蓋。

Source 變更：14 files，`562` insertions、`278` deletions。這個行數含雙語 copy 與 regression tests，不能等同 840 行新產品能力。
