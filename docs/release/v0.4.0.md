# v0.4.0

[繁體中文](v0.4.0.zh-TW.md) · [Release index](README.md)

The owner selected **v0.4.0 stable with new features**. This record is being
prepared; the frozen installer build, publication and exact delivery observations
will be recorded here when complete. The current published release remains v0.3.1.

## Changes

- Optional ZAP passive website checks crawl one approved origin, preserving
  upstream alerts, instances, severity, evidence and remediation.
- Optional Agentic Radar inventory reads one saved repository with a selected
  LangGraph, CrewAI, n8n, OpenAI Agents or AutoGen framework. It runs offline,
  preserves parser diagnostics and never turns graph inventory into vulnerabilities.
- Optional Garak model checks use one approved OpenAI-compatible HTTPS chat API
  and model, 54 unchanged native DAN/ANSI prompts and four native detector pairs.
  The app requires fresh consent and a one-shot local key; TLS verification,
  no redirects, request/deadline limits and provider charges are explicit.
- Kubescape malformed or unevaluated results remain incomplete, while completed
  sibling findings survive. Large reports stream within the evidence budget.
- Greenbone work and resume state bind to each exact approved grant.
- HTML report layouts handle long identifiers and tablet widths. Microsoft 365
  platform identification is corrected.
- Gitleaks `8.30.1-2` fixes the reproducible fixture build. Every engine and the
  gateway has [build/update notes](../engines/image-build-index.md) covering
  fixed inputs, data, patch exceptions and coupled changes.

The gateway image remains the existing verified `0.3.0-1` publication; changing
the desktop version does not rebuild unchanged gateway bytes.
