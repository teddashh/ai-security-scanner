# v0.1.3 historical change summary

This record summarizes the Windows first-run changes made on the `v0.1.3` line. It is not current guidance; see the [product specification](../product-spec.md).

## Useful changes retained

- Windows prerequisite work used the normal administrator-confirmation dialog instead of asking a beginner to type commands.
- A required restart stayed visible and under the user's control.
- The privileged backend derived one fixed action from the detected prerequisite state; the webview could not provide an executable or arguments.
- The action used Windows' own `wsl.exe`, did not receive an administrator password, did not install a Linux distribution, and did not restart the computer.
- The same plain-language state appeared in English and Traditional Chinese.

The later Repair screen and manual-command fallback from this historical flow are superseded. Current product direction keeps runtime infrastructure out of the beginner journey and never treats a localhost TCP connection as a security scan.
