This package collects all 32 commits after the v0.4.1 source (`94ef7be18e83630553d9a72746b0533695df1ee2`) through `c5a0a6693a1ad9997ee16b9a3d690d38a44b7406`. ## Desktop and reports

- **One problem card for one problem.** Group the same vulnerable package, exposed secret, or same-line code findings with the same CWE. Retain original findings, upstream identifiers, evidence, severity and remediation. Show original-finding counts and the representative chosen by the report.
- **Check fixes by problem card.** Track fixed, partly fixed, remaining and new problems. Preserve a card's representative when its line moves; show how many original findings remain when partly fixed. The app and HTML comparison use the same order as Results.
- **Use the latest local folder.** Reselect a folder before checking fixes and scan a fresh read-only snapshot within its approved scope. Saved evidence remains available for comparison. My scans counts problems from the latest finished scan.
- **More useful next steps.** Cloud configuration, identity and cloud-resource findings have fitting labels and actions. Grouped next steps explain whether one fix applies, where to make it and how to check it. Upstream severity, benchmark classification and product priority remain distinct.
- **Clear progress and scanner details.** Distinguish partial completion from failure. Show scanner versions and update dates, including source-built version and commit details. Inventory tools no longer request irrelevant vulnerability-data updates.

## Package verification

The package workflow binds installers, checksums, runtime manifests, notices, SBOMs and platform observations to one exact source commit. Finalized metadata determines which installers are actually offered. Run and artifact references will be recorded after completion.

Local preparation passed 2,193 Rust tests (one public-example generator intentionally ignored), 902 frontend tests, 569 component tests, 203 release-evidence tests, 91 CI contracts and eight engine contracts. All 213 tracked engine inputs have recorded hashes across 25 plans. Type checking, formatting, production build, release identity and the complete packaging self-test passed. The 33 local PowerShell fixture tests were skipped because `pwsh` is unavailable; this is not a live-cloud test.

Windows installers remain unsigned and macOS remains unnotarized. Previous runtime and installed-app observations belong to their original artifacts; they are not new v0.5.0 observations. This packaging work does not authorize new external-target scans.
